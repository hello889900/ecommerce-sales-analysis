# E-Commerce Sales Data Analysis

## Project Overview
This project analyzes an e-commerce dataset containing 9,696 records to understand sales performance, profitability, customer behavior, product performance, and shipping delays.

## Objectives
- Analyze total revenue, profit, and quantity sold.
- Identify top-performing products, categories, and states.
- Compare sales performance across customer segments.
- Examine the impact of discounts on profitability.
- Analyze shipping delays using order and shipping dates.

## Dataset
The dataset contains the following columns:
- Order Details: `order_id`, `order_date`, `ship_date`, `ship_mode`
- Customer Details: `customer_id`, `customer_name`, `customer_type`
- Location: `country`, `city`, `state`, `postal_code`, `region`
- Product Details: `product_id`, `product_category`, `sku`, `product_name`
- Sales Metrics: `revenue`, `quantity`, `discount`, `profit`

## Tools and Technologies
- Python
- Pandas
- MySQL
- SQL
- Google Colab

## Project Workflow
1. Inspected the dataset and identified missing values and data inconsistencies.
2. Cleaned and preprocessed the data using Python and Pandas.
3. Prepared the cleaned dataset for analysis.
4. Used SQL queries to calculate sales, profit, and quantity metrics.
5. Analyzed product performance, customer segments, discount impact, and shipping delays.

## Key Analysis Areas
- Sales and profit analysis
- Product and category performance
- Regional and state-wise profitability
- Customer segment analysis
- Discount and loss analysis
- Shipping delay analysis
- Monthly and yearly sales trends

## Skills Demonstrated
Data Cleaning, Data Preprocessing, Exploratory Data Analysis (EDA), SQL Querying, Data Analysis, and Problem-Solving.

## Conclusion
This project demonstrates how data cleaning and SQL analysis can transform raw e-commerce data into meaningful business insights to support better decision-making.
